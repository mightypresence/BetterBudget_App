## A. 設計語言（Design Language）

### A1. 整體風格定調

**「暖感極簡理財」— Warm Minimalist Finance**

- **三個關鍵詞**：溫暖、精緻、信賴感
- **風格方向**：現代日系／北歐極簡理財 App（參考：YNAB 的清晰 + Moneytree 的質感 + Spendee 的圖表美感）
- **核心差異**：不像傳統記帳 App 冷冰冰的試算表感，而是像一本**精心設計的個人財務手帳**——溫暖的米白底色、柔和漸層、圓潤卡片、精緻微互動
- **深色模式**：支援 AMOLED 純黑基底 + 暖色點綴，不只是反色，而是獨立設計的夜間質感
- **Material 3 為底，大量客製**：使用 Material 3 Token 系統但自訂全部 ColorScheme、Shape、Typography，不依賴預設

### A3. 字型系統

#### 中文字型

- **主要**：Noto Sans TC（Google Fonts，免費可商用）
  - `Display / Headline` 使用 **Noto Sans TC Medium**（500 weight）
  - `Title / Body` 使用 **Noto Sans TC Regular**（400 weight）
  - `Label` 使用 **Noto Sans TC Medium**（500 weight）
- **備用**：系統預設中文字型（蘋方 / 思源黑體）

#### 英數字型

- **主要**：Inter（Google Fonts，免費可商用）
  - 金額數字使用 **Inter SemiBold**（600 weight）+ **Tabular Figures**（等寬數字，讓金額對齊）
  - 一般文字使用 **Inter Regular**（400 weight）

#### Flutter 整合方式

```dart
// pubspec.yaml 加入
// google_fonts: ^6.1.0

// main.dart 主題設定
theme: ThemeData(
  fontFamily: 'Noto Sans TC',
  textTheme: GoogleFonts.notoSansTCTextTheme().copyWith(
    // 金額數字使用 Inter
    headlineLarge: GoogleFonts.inter(
      fontWeight: FontWeight.w600,
      fontFeatures: [FontFeature.tabularFigures()],
    ),
  ),
)
```

#### 排版層級

| 層級 | 大小 | Weight | 行高 | 用途 |
|------|------|--------|------|------|
| `displayLarge` | 36px | 600 | 1.2 | 首頁總金額 |

### A4. 圓角／陰影／間距系統

#### 圓角（Border Radius）

| 層級 | 數值 | 用途 |
|------|------|------|
| `xs` | 6px | 小元件（Chip、Badge） |
| `sm` | 10px | 按鈕、輸入框 |
| `md` | 16px | 一般卡片 |
| `lg` | 20px | 大型卡片（Hero 總覽卡） |
| `xl` | 24px | Dialog、Bottom Sheet |
| `full` | 999px | 膠囊按鈕、Avatar |

#### 陰影（Elevation / Box Shadow）

- **不使用 Material 預設 shadow**，全部改用自訂柔和陰影：
  - 卡片陰影（常態）：
    ```css
    box-shadow: 0px 2px 8px rgba(0,0,0,0.06), 0px 0px 0px 1px rgba(0,0,0,0.04);
    ```
  - 卡片陰影（hover / active）：
    ```css
    box-shadow: 0px 4px 16px rgba(0,0,0,0.08), 0px 0px 0px 1px rgba(0,0,0,0.04);
    ```
  - FAB 陰影：
    ```css
    box-shadow: 0px 4px 20px rgba(79,107,90,0.25);
    ```
  - Bottom Sheet / Dialog：自帶的 Material 陰影即可，但改為較柔和的 overlay color

#### 間距（Spacing）

| Token | 數值 | 用途 |
|-------|------|------|
| `xxs` | 4px | icon-text 間隙 |
| `xs` | 8px | 同組元件間隙 |
| `sm` | 12px | 卡片內部 padding |
| `md` | 16px | 頁面 padding、卡片間距 |
| `lg` | 24px | 區塊間距 |
| `xl` | 32px | 大區塊分隔 |
| `xxl` | 48px | Hero 區塊上下 |

---

### A5. 圖示風格

- **使用 Phosphor Icons（`phosphor_flutter` 套件）**
  - Phosphor 有 6 種 weight（Thin / Light / Regular / Bold / Fill / Duotone）
  - 一般 icon 使用 `Regular`（24px）
  - 選中／啟動態使用 `Fill`
  - 導航列主要項目使用 `Bold`
  - 提供一致、現代的視覺語言，遠優於 Material Icons 的混搭感
- **icon 大小標準**：24px（一般）、20px（列表 Tile 內）、32px（Hero 區塊）
- **自訂類別圖示**：使用者可從 100+ Phosphor icon 中選擇（現有只有 13 個 Material icon，遠不夠）

#### B1-2. 元件細節

**A. Hero 總覽卡**
- 全寬卡片，`border-radius: 20px`，背景為 `Primary Container` 色（`#D6E8DB`）
- 左上角小標籤「本月可用餘額」→ 使用 `bodySmall` + `Secondary` 色
- 大數字金額使用 `displayLarge` + Inter SemiBold + Tabular Figures
- 金額下方進度條：8px 高、圓角，顏色從綠色漸層到黃到紅（依剩餘比例）
  - 實作方式：`LinearGradient` + `ClipRRect`
- 底部兩行小字：「收入 +150,000    支出 −21,500」
  - 收入用 `Tertiary` 色，支出用 `Error` 色（若當月有支出）
- 右上角放一個小型折線圖 icon（暗示點擊可展開月趨勢）→ 點擊進入月報表

**B. AppBar**
- **左側**：抽屜選單 icon（`PhosphorIcons.list`）
- **中間**：月份顯示（`「2026 年 8 月」`）+ 左右箭頭切換（`< >`）
  - 支援左右滑動整頁切換月份（GestureDetector + PageView 概念）
- **右側**：通知鈴鐺（若有超支或待分配）+ 使用者頭像（若有）

**C. 待分配提醒**
- 條件顯示：只在 `unassigned > 0` 時顯示
- 卡片背景：暖黃漸層（`#FFF3D6` → `#FFE8B0`），取代目前的綠色半透明
- 左側 icon：`PhosphorIcons.coins`（Fill, 金幣動畫）
- 文字：「還有 NT$ 12,000 待規劃」使用 `titleMedium` + 棕色字
- 右側按鈕：「馬上分配 →」使用 `TextButton` + 跳動微動畫
- 點擊整個卡片進入 `AllocationScreen`

**D. 預算圓環圖（Donut Chart）**
- 使用 `fl_chart` 套件繪製甜甜圈圖
- 中心空洞半徑 70%，中心顯示「已用 / 總預算」+ 百分比
- 每個扇形對應一個類別，用該類別顏色
- 超支類別的扇形超出 100% 時，以紅色標示並有輕微脈衝動畫
- 點擊扇形 → navigate 到該類別明細（未來功能）
- 圖例放在下方，水平排列（用 `Wrap`）

**E. 類別卡片（水平滑動）**
- `SizedBox(height: 140)` + 水平 `ListView`（`scrollDirection: Axis.horizontal`）
- 每張卡片：寬 130px、`border-radius: 16px`、白色底 + 柔和陰影
- 內容由上而下：
  - icon（32px）+ 類別名稱（`bodySmall`）
  - 進度條（6px 高、圓角、類別顏色，超支變紅）
  - 已花金額（`bodyLarge` + bold）+ 「剩 X,XXX」或「超 X,XXX」（`bodySmall`）
- 滑動到最右有「＋」卡片 → 新增類別
- 點擊卡片 → 彈出該類別本月明細

**F. 最近交易列表**
- 顯示最近 5 筆交易，每筆一行
- 左側：類別 icon（小圓形）+ 類別名稱（或備註）
- 右側：金額（支出紅色負號、收入綠色正號）
- 日期顯示在最右或副標
- 最下方「查看全部 →」→ 進入本月交易列表（新畫面）

**G. FAB（FloatingActionButton）**
- 右下角，`border-radius: full`（膠囊形）
- 文字：「＋ 記一筆」（非只有 icon）
- 顏色：Primary `#4F6B5A`
- 陰影：`0px 4px 20px rgba(79,107,90,0.25)`
- 按下有 scale-down 動畫（`AnimationController` 0.95x）

#### B2-2. 元件細節

**A. 支出／收入切換**
- 不是用 Material `SegmentedButton`（太像系統 UI）
- 兩個大卡片並排，`border-radius: 16px`，高度 80px
- 選中態：Primary Container 背景 + Primary 邊框 2px + 輕微 scale-up（1.03x）
- 未選中態：Surface Container Low 背景 + 半透明邊框
- 切換時有 200ms crossfade 動畫
- icon 使用 Phosphor：支出 = `PhosphorIcons.arrowDown`，收入 = `PhosphorIcons.arrowUp`

**B. 金額輸入**
- 不是一般 `TextField`，而是大卡片區域
- 顯示「NT$」前綴（`bodyLarge`）+ 正在輸入的數字（`displayLarge` + Inter SemiBold）
- 下方游標閃爍效果
- 鍵盤：純數字鍵盤（`keyboardType: number`），系統自動
- 金額為 0 或空時，顯示灰色的 placeholder：「0」

**C. 快速金額按鈕**
- 膠囊形 Chip，`border-radius: full`
- 預設：[100] [200] [500] [1,000] [5,000]
- 可以在設定中自訂
- 點擊後加到目前金額（累加），而非取代
- 按壓時有輕微 scale 動畫

**D. 類別選擇**
- 水平網格（`GridView` horizontal），每個格子 64x64
- icon 32px + 標籤 11px
- 選中態：icon 變 Fill weight、格子變 Primary Container 色
- 支援約 20 個自訂類別（未來可展開）
- 若無類別，顯示「＋ 建立類別」空狀態方塊

**E. 儲存後流程**
- 儲存成功 → SnackBar 從上方優雅出現（非底部，與 FAB 不重疊）
- 若為收入 + 預算規劃開啟 → 自動導向分配畫面（現有邏輯保留但 UI 需改）
- 若為支出 + 超支 → SnackBar 顯示溫馨提醒「這個類別本月已超支，要注意喔」

### B3. 收入分配引導畫面（核心特色）

> **這是零基記帳最重要的差異化畫面。目前的設計是「表單填數字」，極度缺乏引導感和樂趣。重新設計的目標是：讓使用者感覺像在玩一個「把錢放進信封」的療癒遊戲。**

#### B3-1. 設計概念：「虛擬信封分配盤」

#### B3-3. 核心互動

**A. 快速加減按鈕**
- 每個類別卡片右側有 `[−]` 和 `[＋]` 按鈕
- 點擊 `[＋]`：以 $1,000 為單位增加（可在設定中更改步進值）
- 長按 `[＋]`：連續快速增加（`repeat` 機制）
- 點擊 `[−]`：減少 $1,000
- 金額變化有數字彈跳動畫
- 也可直接點擊中間數字叫出鍵盤手動輸入

**B. 進度條預覽**
- 每個類別卡片內的水平進度條顯示「已分配 / 上限」
- 顏色變化：
  - 0-50%：淺灰 → 提供「還沒分配夠」的暗示
  - 50-90%：主色綠 → 「健康範圍」
  - 90-100%：深綠 → 「接近滿額」
  - >100%：橘色 → 「已超出上限，注意！」

**C. 拖曳分配（Phase 2 功能）**
- 長按類別卡片可拖曳到另一個類別（轉移分配）
- 頂部進度條即時更新
- 釋放時有成功觸覺回饋（HapticFeedback）

**D. 智慧建議按鈕**
- 「套用上月比例」：根據上個月各類別的分配比例，自動分配本月收入
  - 套用前先預覽（顯示各類別會分到多少），確認後一次套用
- 「自動填滿」：將剩餘金額按比例分配到尚未達上限的類別

**E. 完成規劃動畫**
- 按下「完成規劃」→ 所有信封卡片向上飛出 + 中央出現「🎉 規劃完成！」+ 灑花粒子動效
- 自動回到首頁，Hero 卡數字刷新

#### B3-4. 空狀態
- 若沒有類別，顯示：「還沒有預算類別，先去設定吧」+ 跳轉按鈕

     - **長條圖**（Bar）：每月收入 vs 支出趨勢（6 個月）
     - **折線圖**（Line）：各類別月度支出變化
   - 報表頁面可從首頁圖表點擊進入

3. **交易搜尋與篩選**
   - 搜尋列（關鍵字、備註）
   - 篩選：類別、日期範圍、金額範圍、收入/支出
   - 排序：日期、金額

4. **類別自訂顏色與圖示**
   - 目前所有類別共用 `0xFF6750A4`（紫色）
   - 改為從色盤選擇顏色（10+ 顏色）
   - icon 從 Phosphor 40+ 選擇

#### 🟡 P1（第二階段，體驗升級）

5. **月結轉功能**
   - 每月結束時，可將「未花完的預算」結轉到下個月
   - 或結轉到儲蓄類別
   - 一鍵操作 + 動畫效果

6. **多帳戶管理**
   - 現金、銀行 A、銀行 B、信用卡
   - 每筆交易選擇帳戶
   - 各帳戶餘額獨立追蹤
   - 帳戶間轉帳功能

7. **常用交易模板**
   - 儲存常用交易組合（如：每月固定訂閱費、房租）
   - 一鍵新增整組交易
   - 可設定每月自動提醒

8. **預算提醒推播**
   - 類別支出達 80%/100% 時推播提醒
   - 超支時即時通知
   - 可自訂提醒閾值

9. **手勢操作**
   - 首頁下拉重整
   - 交易列表左滑刪除
   - 類別卡片長按拖曳排序
   - 收入分配畫面拖曳調整金額（Phase 2）

#### 🟢 P2（第三階段，差異化亮點）

10. **AI 智慧建議**
    - 根據過去幾個月的支出模式，建議下個月預算分配
    - 「這個月你在餐飲花了較多，建議調整伙食預算」
    - 異常支出偵測（突然的大筆支出）

11. **資料匯出**
    - 匯出 CSV / PDF 報表
    - 每月自動寄送報表到 Email（搭配背景服務）

12. **iCloud / Google Drive 備份**
    - 自動備份到雲端
    - 跨裝置同步（搭配雲端備份）

13. **Widget（桌面小工具）**
    - iOS Lock Screen Widget / Android App Widget
    - 顯示本月剩餘預算、快速記帳按鈕

14. **多人即時同步（共同帳本升級）**
    - 透過 Cloud Firestore 或自建後端
    - 共同帳本變更即時推送
    - 交易新增／修改即時通知

## D. 特色功能 — 與競品差異化

### 與 YNAB 的差異

| 面向 | YNAB | 零基記帳（本規劃） |
|------|------|-------------------|
| 視覺風格 | 功能導向、嚴肅、像試算表 | 溫暖、精緻、像手帳 |
| 分配體驗 | 表格式輸入 | **信封分配盤**：拖曳、快速加減、進度預覽 |
| 共同帳本 | 無原生支援 | **原生共同帳本**：4 種分攤、私房錢功能 |
| 中文化 | 英文介面、國外銀行 | **繁體中文優先**、台灣用語、NT$ |
| 遊戲化 | 無 | **完成規劃灑花**、數字彈跳動畫、成就徽章（P2） |
| 價格 | 年費 US$99 | **免費／低價** |

### 與记帳城市／Moneybook 的差異

| 面向 | 記帳城市 / Moneybook | 零基記帳 |
|------|---------------------|---------|
| 核心方法 | 傳統記帳（事後記錄） | **零基預算**（事前規劃） |
| 預算哲學 | 被動追蹤 | **主動分配每一塊錢** |
| 使用者引導 | 自動分類而已 | **收入進來就引導分配** |
| 共同帳本 | 無或陽春 | **原生支援 + 私房錢** |

### 差異化亮點（Unique Selling Points）

1. **🎯 信封分配盤**（見 B3）
   - 市場上沒有記帳 App 用「虛擬信封」的互動設計來做零基預算
   - 結合「快速加減」、「拖曳」、「智慧建議」三個層次的互動
   - 讓「規劃預算」從苦差事變成療癒的日常儀式

2. **🫙 私房錢機制**
   - 共同帳本中「實際收入 ≠ 顯示收入」的設計
   - 可愛的撲滿動畫讓嚴肅的金錢話題變得輕鬆
   - 增進伴侶間的財務透明與信任

3. **🎨 暖感極簡設計語言**
   - 不是冰冷的理財工具，而是有溫度的財務夥伴
   - 米白底色、柔和陰影、圓潤卡片、精緻動效
   - 讓使用者「願意打開 App」而不是「必須打開 App」

4. **⚡ 智慧分配建議**
   - 一鍵套用上月比例
   - 自動填滿剩餘額度
   - 未來 AI 異常偵測與建議

5. **📊 直覺報表**
   - 圓環圖 + 長條圖 + 折線圖
   - 不是冷冰冰的數字，是有顏色的財務故事
