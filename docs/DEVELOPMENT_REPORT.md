## 一、專案總覽

**零基記帳**是一款以「零基預算（Zero-Based Budgeting）」為核心的繁體中文記帳 App。與傳統「事後記帳」不同，它的核心體驗是：**收入進來 → 主動引導你把每一塊錢分配到各預算類別**（YNAB 的「Give every dollar a job」哲學），讓使用者從「被動追蹤花費」變成「主動規劃金錢」。

**市場定位（參考競品研究）**：台灣第一款「**零基預算 + 主題個性化**」記帳 App。

## 三、設計理念

### 3.1 核心哲學：讓每一塊錢都有任務

- **收入引導分配**：記完收入後，App 主動詢問「要規劃這筆錢嗎？」→ 將收入分配到各類別（像把錢放進信封）
- **待分配池**：未規劃的錢顯示為「待分配」，時刻提醒
- **即時餘額**：每個類別顯示「剩 X,XXX / 超 X,XXX」，預算狀態一目瞭然

### 3.2 設計語言：暖感極簡理財

- 不像傳統記帳 App 冷冰冰的試算表感，而是**溫暖的個人財務手帳**
- 米白底色、柔和陰影、圓潤卡片、森林綠主色、Inter 等寬金額數字
- 完整 Token 系統（色彩/字型/圓角/間距），支援深色模式

### 3.3 體驗設計決策（使用者主導）

| 決策 | 理由 |
|---|---|
| **首屏＝快速記帳** | 使用者打開 App 就是要「快速記一筆」，記帳應零摩擦 |
| **規劃藏角落** | 預算規劃是「偶爾要做的事」，不應擋在記帳前面 |
| **共同帳本** | 情侶/家庭財務透明；**私房錢**讓敏感話題變輕鬆 |

### 3.4 主題系統（市場藍海）

競品研究發現：**記帳 App 的主題/個性化是藍海**——僅「記帳城市」有真正的主題更換（36+ 主題付費解鎖），YNAB、麻布、Money Lover、EveryDollar 全部沒有。我們提供 **6 款主題**（經典森林、海洋藍、暗夜霓虹、粉彩甜心、大地暖棕、石墨科技），全部支援亮/暗色，付費主題一次解鎖終身使用。

## 五、收費策略

### 5.1 模式：Freemium + 終身買斷 + 主題內購

**定價依據（競品研究）**：
- Money Lover 終身買斷 ≈ NT$600（直接競品）
- 麻布記帳年費 NT$690→1,499（我們終身價≈麻布一年）
- 記帳城市訂閱 NT$2,290/年（證明用戶願為視覺內容付費）
- 台灣用戶訂閱疲勞 → **終身買斷是強力轉換誘因**

### 5.2 功能分層

| 層級 | 價格 | 內容 |
|---|---|---|
| **免費版** | NT$0 | 核心零基預算（收入分配全功能）、3 個預算類別、基礎報表、2 款免費主題、共同帳本基本 |
| **Pro（終身買斷）** | **NT$590** | 無限預算類別、全部 6 款主題、全部報表、去廣告、雲端備份（未來）、共同帳本擴充（未來） |
| **主題商店（內購）** | NT$30-90/款 | 設計師主題包，可單買或含在 Pro 內 |

### 5.3 定價策略理由

1. **核心功能免費**：零基預算是差異化，免費提供讓用戶「先上癮再升級」
2. **限制數量而非功能**：限「3 個類別」而非閹割分配功能——升級動機自然
3. **終身 NT$590 建立信任**：低於麻布年費、遠低於記帳城市，主打「付一次、用永久」
4. **主題商店持續營收**：主題邊際成本趨零、毛利極高，可與台灣插畫家/IP 聯名
5. **早鳥策略**：限時 NT$390 衝初期用戶量

### 5.4 實作狀態

- ✅ 主題商店：6 款主題、付費解鎖、購買流程（示範模式）
- ✅ Pro 分層：免費 3 類別上限 → 升級 NT$590（示範模式）
- ⏳ 正式金流：串接 App Store / Google Play 內購（IAP），付款後自動解鎖

## 八、結論

零基記帳以**「零基預算引導 + 主題個性化 + 共同帳本」**三位一體切入市場：
- 方法論面：YNAB 證明有效（但太貴、無繁中）
- 視覺面：主題是藍海（競品幾乎沒做）
- 台灣面：繁中優先、NT$ 情境、發票載具規劃

**收費策略**：免費版給足核心體驗 → 終身 NT$590 建立信任 → 主題商店創造持續營收。這套組合在台灣市場具備明確的競爭力與差異化空間。
